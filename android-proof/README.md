# Survive 60 Android fallback (test only)

A free Android WebView proof-of-concept build for the published Survive 60 game. It is not yet a reviewed or signed production release. It is maintained separately from the currently approved ONEplay web game and Toss RC54 bundle. Production needs a release keystore kept off public GitHub, on-device gameplay QA, store approval, and game classification verification. No paid services or ad traffic generation are part of this project.
