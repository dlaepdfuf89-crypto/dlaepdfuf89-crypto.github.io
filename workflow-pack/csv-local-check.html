거래 CSV 파일, 맡길 수 있는 형식인지 먼저 확인하세요.

원본 파일을 브라우저 안에서만 읽어 필수 열 이름·총 행 수·인코딩·크기 제한을 확인합니다. 이 페이지는 파일 전송·결제·매출 집계를 수행하지 않습니다.

CSV 1~5개 선택

필수 열 7개

거래일, 거래처코드, 거래처, 상품코드, 상품명, 수량, 단가 (열 순서는 달라도 됩니다)

기본 상한

CSV 최대 5개 / 전체 데이터 10,000행 / 파일별 10MiB / 전체 20MiB. UTF-8 또는 CP949.

개인정보가 포함된 실제 거래 파일을 선택하더라도 파일 내용은 이 브라우저를 떠나지 않습니다. 개인정보 보호를 위해 PC에서 직접 검사하고, 공용 컴퓨터에서는 사용하지 않는 것이 좋습니다.

검사에서 확인하지 않는 것

이 페이지는 구조 점검만 합니다. 금액 합계, 거래 날짜의 실제 유효성, 고객·상품코드 충돌, 취소·반품, 세금 규칙, 개인정보 처리 적법성, 파일 내용 전체의 업무상 정확성을 검증하지 않습니다. 검사가 통과해도 납품을 보장하지 않으며 실제 작업 가능 여부와 납기는 상담 후 확정합니다.

다른 열 이름이나 XLSX를 사용하나요? 현재 99,000원 기본 상품은 고정된 7개 한국어 필수 열의 CSV를 대상으로 합니다. 그 밖의 형식은 제공을 보장할 수 없으므로 구매 전 별도 상담부터 진행해 주세요.
