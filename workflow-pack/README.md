# WORKFLOW PACK — 엑셀 붙여넣기 거래내역 오류검사

**엑셀 표를 복사해 붙여넣으면 바로 거래 오류를 확인하고 매출을 집계할 수 있는 무료 웹 도구입니다.** 별도 업로드 서버, 로그인, 유료 API 없이 브라우저에서 처리합니다.

### 이런 문제를 해결합니다

매출 거래내역을 엑셀로 관리할 때 잘못된 날짜, 빈 수량, 단가 누락 때문에 월별 합계가 맞지 않는 경우가 있습니다. WORKFLOW PACK은 **정상행과 확인이 필요한 오류행을 분리하고, 거래처·상품별 수량과 금액을 계산**합니다. 무료 검수 결과는 CSV 파일로 각각 저장할 수 있습니다.

1. 엑셀에서 거래 **열 제목을 포함해** 표를 복사합니다.
2. 웹 앱의 **'엑셀 복사·붙여넣기'** 창에 붙여넣고 검사 버튼을 누릅니다.
3. 정상 거래, 제외 사유, 거래처·상품별 집계를 확인하고 필요한 CSV 결과물을 내려받습니다.

> 지원되는 열 제목: `거래일`, `거래처코드`, `거래처`, `상품코드`, `상품명`, `수량`, `단가`. 코드 열이 없는 다른 형식은 임의로 추정해 합산하지 않습니다.

### 가상 예제

| 거래일 | 거래처코드 | 거래처 | 상품코드 | 상품명 | 수량 | 단가 |
|---|---|---|---|---|---:|---:|
| 2026-10-21 | 001 | 가상상사 | 0007 | 샘플상품 | 2 | 10000 |
| 2026-10-22 | 001 | 가상상사 | 0007 | 샘플상품 | 3 | 5000 |
| 2026-02-30 | 002 | 샘플마트 | 0008 | 체험상품 | 1 | 2000 |

위 예제에서 **2026-02-30은 존재하지 않는 날짜**이므로 집계에서 제외됩니다. 이는 실제 고객 실적이 아니라 제품 이해를 위한 가상 테스트입니다.

### 처리와 보안

무료 검사 기능은 클라이언트 브라우저에서 동작하며 입력 데이터는 운영자 서버로 전송하지 않습니다. Excel `.xlsx` 파일 자체를 직접 여는 기능은 제공하지 않으며, 엑셀에서 **표를 복사해서 붙여넣거나 CSV(.csv) 파일을 선택**하는 방식입니다. 날짜·수량·단가의 기본 유효성 검사는 세금 신고용 확정 매출이나 취소·반품 처리의 정확성을 보장하지 않습니다.
