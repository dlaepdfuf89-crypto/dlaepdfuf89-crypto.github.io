거래 CSV 통합·검수 대행 99,000원 확인

현재 판매 중인 STANDARD는 같은 구조의 CSV 최대 5개, 총 10,000행까지 지원합니다. 원본에 개인정보가 있다면 공개 문의에 첨부하지 마세요.

1. 파일을 열기 전 확인할 것

  • 파일이 CSV인지 확인합니다. .xlsx는 현재 기본 상품 지원 대상이 아닙니다.
  • 열 이름이 거래일, 거래처코드, 거래처, 상품코드, 상품명, 수량, 단가인지 확인합니다.
  • 서로 다른 파일에도 동일한 열 이름과 의미가 쓰였는지 검사합니다.
  • 코드 앞자리 0이 사라지지 않도록 스프레드시트 가져오기 때 코드 열을 문자로 취급합니다.

2. 오류가 발생하기 쉬운 데이터

  1. 날짜: 형식이 맞아도 2026-02-30처럼 실제 없는 날짜는 제외 대상입니다.
  2. 수량: 공란·문자·0 이하 값은 정상 판매 수량으로 계산하지 않습니다.
  3. 단가: 숫자 여부와 허용 범위를 확인하고, 금액은 수량 × 단가로 계산합니다.
  4. 거래처 코드: 동일 코드에 서로 다른 거래처명이 사용되면 원자료를 확인합니다.
  5. 상품 코드: 비어 있거나 서로 다른 명칭과 충돌하면 원본 행 번호를 남겨 검토합니다.

취소·반품·세금·중복 주문 여부는 각 회사의 거래 규칙에 따라 다를 수 있으므로 일괄 추정하면 안 됩니다.

3. 결과를 나누어 전달하는 이유

검증에 통과한 행을 모은 정상 거래 통합표, 거래처·상품별 수량·금액 집계표, 계산에 넣지 않은 오류행 목록을 구분해야 수정과 재검증이 쉽습니다.

예를 들어 가상 5행 중 정상 3행의 총금액이 55,000원이고 오류 2행이 발견됐다면, 55,000원은 전체 확정 매출이 아니라 오류행을 제외한 부분 집계임을 표시해야 합니다. 실제 고객 실적이 아닌 설명용 가상 자료입니다.

4. 직접 점검하거나 대행 맡기기

기본 파일 구조를 먼저 확인하려면 무료 CSV 구조 점검기를 사용하세요. 파일이 서버로 업로드되지 않으며 행 수·필수 열 같은 기초 조건을 확인하는 도구입니다.

여러 파일의 정상 거래 병합·거래처별 금액 집계·오류 목록 분리가 필요하면 국내 STANDARD 99,000원 상품에서 요청할 수 있습니다. 구매 전 고정 7열 조건과 납기를 확인하세요.
