1. 먼저 확인할 7개 열

현재 예제 및 서비스는 한국어 열 이름 거래일, 거래처코드, 거래처, 상품코드, 상품명, 수량, 단가를 사용합니다. 임의의 ERP·엑셀 형식이나 서로 다른 열 이름은 자동 변환 대상이 아닙니다.

한 행의 금액 = 수량 × 단가. 숫자가 아니거나 수량이 0 이하이면 정상 금액 집계에 넣지 않습니다. 날짜는 실제 존재하는 YYYY-MM-DD 형태여야 합니다.

2. 가상 거래 5건을 검수하는 예

거래처상품수량단가판정
A상사X상품210,000원정상
A상사X상품310,000원정상
B상사Y상품15,000원정상
C상사Z상품공란8,000원오류: 수량 누락
D상사X상품19,000원오류: 존재하지 않는 날짜

정상 거래만 계산하면 A상사 X상품 5개·50,000원, B상사 Y상품 1개·5,000원, 합계 55,000원입니다. 오류 2건은 원본 행 번호와 오류 사유를 따로 보관해야 합니다. 이 값은 실제 고객 매출이 아닌 가상 예시입니다.

3. 파일을 합칠 때 실수하기 쉬운 지점

  1. 서로 다른 거래처 코드를 같은 거래처명이라는 이유만으로 무조건 합치지 않습니다.
  2. 상품코드 앞의 0이 엑셀에서 사라지지 않게 텍스트 형식으로 불러옵니다.
  3. 오류가 있으면 정상 거래 합계는 부분 집계임을 표시합니다.
  4. 서로 다른 파일의 중복 거래, 취소·반품·부가세 처리는 별도 규칙이 없으면 추정하지 않습니다.

파일 구조와 오류 종류를 먼저 확인하고 싶다면 무료 로컬 CSV 구조 점검기를 사용하세요. 파일을 서버로 전송하지 않고 필수 열·파일 수·행 수 같은 기본 구조를 검사합니다.

4. 직접 처리하기 어렵다면

현재 판매 중인 국내 STANDARD 상품은 같은 구조의 CSV 최대 5개·전체 10,000행까지 통합해 정상 거래 CSV, 거래처·상품별 집계 CSV, 오류 목록 CSV를 제공하는 일회성 대행입니다. 최대 파일 용량 및 작업 범위는 주문 전 판매 페이지에서 확인하세요.
