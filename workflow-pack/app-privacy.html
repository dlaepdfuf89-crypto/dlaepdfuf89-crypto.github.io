안드로이드 운영체제, 앱 마켓 또는 토스 호스트 애플리케이션이 독립적으로 처리하는 플랫폼 정보는 각 서비스의 개인정보 처리 정책이 적용됩니다. 본 방침은 운영자가 제공하는 CSV 검수 기능의 데이터 처리에 관한 설명입니다.

파일은 사용자가 시스템 파일 선택 기능으로 선택한 경우에만 브라우저 또는 기기의 앱 실행 환경에서 읽습니다. 별도 계정 권한이나 기기 전체 저장소 접근 권한을 요구하지 않으며, 앱은 원본 파일을 덮어쓰지 않습니다. CSV 결과는 사용자가 직접 저장할 때 지정한 위치에 생성됩니다. 결과 CSV에는 스프레드시트 수식 실행을 방지하기 위한 값 인코딩이 적용됩니다.
