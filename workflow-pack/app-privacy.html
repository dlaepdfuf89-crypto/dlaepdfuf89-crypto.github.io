개인정보처리방침

대상 앱: WORKFLOW PACK CSV 검수 (Android 앱 및 토스 미니앱)
시행일: 2026년 10월 26일

WORKFLOW PACK CSV 검수는 사용자가 직접 선택한 거래 CSV 파일의 형식·오류·거래처 및 상품별 합계를 분석하는 도구입니다. 앱의 운영자는 이용자 정보의 보호를 중요하게 생각합니다.

1. 접근하는 정보와 처리 목적

앱은 사용자가 명시적으로 선택한 CSV 파일의 파일명, 데이터 열 이름 및 거래 데이터 내용에 접근합니다. 날짜·수량·단가 등 입력 검증, 오류·제외행 분리, 거래처·상품별 집계, 사용자가 요청한 CSV 결과물 생성에만 사용합니다. 원본 CSV에는 개인 또는 영업상 민감한 정보가 포함될 수 있으므로 입력 전 필요한 범위의 파일인지 확인하십시오.

2. 수집·외부 전송·제3자 제공

운영자의 CSV 검수 기능은 사용자가 선택한 CSV 파일의 내용을 운영자 서버로 전송하거나 저장하지 않습니다. 별도 회원가입이나 운영자 서버 기반 계정 기능은 없습니다. 토스 미니앱에서는 CSV 검수 결과 화면에 광고를 표시하기 위해 토스의 배너 광고 SDK(TossAds)를 사용하며, 광고 제공·성과 측정 과정에서 토스 및 광고 파트너(Google AdMob 등)가 기기/광고 식별정보, 노출·클릭 관련 정보를 각자의 정책에 따라 처리할 수 있습니다. CSV 파일 내용은 광고 SDK로 전달하지 않습니다.

안드로이드 운영체제, 앱 마켓 또는 토스 호스트 애플리케이션이 독립적으로 처리하는 플랫폼 정보는 각 서비스의 개인정보 처리 정책이 적용됩니다. 본 방침은 운영자가 제공하는 CSV 검수 기능의 데이터 처리에 관한 설명입니다.

3. 처리 방식과 안전 조치

파일은 사용자가 시스템 파일 선택 기능으로 선택한 경우에만 브라우저 또는 기기의 앱 실행 환경에서 읽습니다. 별도 계정 권한이나 기기 전체 저장소 접근 권한을 요구하지 않으며, 앱은 원본 파일을 덮어쓰지 않습니다. CSV 결과는 사용자가 직접 저장할 때 지정한 위치에 생성됩니다. 결과 CSV에는 스프레드시트 수식 실행을 방지하기 위한 값 인코딩이 적용됩니다.

4. 보관·삭제

검수 데이터는 작업 중 앱의 일시적인 실행 메모리에서 사용되며 운영자 서버에 보관되지 않습니다. 앱 종료 또는 프로세스 종료 후 앱은 별도의 작업 내역을 자체 서버에 유지하지 않습니다. 이용자가 기기에 저장한 결과물은 기기 파일 관리 기능으로 직접 확인하고 삭제할 수 있습니다. 계정이 없으므로 계정 삭제 절차는 적용되지 않습니다.

5. 제3자 처리 및 외부 연동

Android 독립 앱의 CSV 검수 기능은 광고·결제 기능 없이 기기 안에서 동작합니다. 토스 미니앱에는 인앱 배너 광고가 표시될 수 있으나 CSV 파일·거래내역을 광고 목적으로 전송하지 않습니다. 광고 관련 정보 처리에 대해서는 토스 개인정보 처리방침과 Google 개인정보처리방침을 확인해 주세요. 외부 유료 서비스는 별도 구매 화면과 조건에 따르며, 이 무료 앱에서 자동 결제가 발생하지 않습니다.
