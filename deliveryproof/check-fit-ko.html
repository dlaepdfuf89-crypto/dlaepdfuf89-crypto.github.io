공식 직접 다운로드는 주문·이메일 입력 없이 무료 ZIP을 받을 수 있습니다. 대안으로 Gumroad에서 무료 주문 시 원하는 가격에 0을 입력하고, 합계 US$0를 확인한 뒤 이메일로 받으세요. 유료판은 별도 구매이며 자동 전환되지 않습니다.

검사 범위와 제한

  • 브라우저 파일 목록 비교: 승인된 CSV/TXT 목록과 선택한 폴더의 상대 경로·파일명을 비교하며 영상 내용은 검사하지 않습니다.
  • 브라우저 SHA-256 비교: 로컬 폴더의 파일 크기와 내용 해시를 비교하지만 파일 하나당 100MiB를 넘으면 미검증으로 표시합니다.
  • Windows 무료 R4: 사전 승인본과 최종 파일을 비교하고 지정된 영상 메타데이터를 검사합니다. 기술 검사 PASS일 때 ZIP을 만듭니다. Windows 사용자 프로필별 성공 ZIP 5회 제한이며 IP별 제한이 아닙니다.

Windows EXE는 코드 서명되지 않았습니다. 제작자 Windows 10 검증만 완료했으며 Windows 11·기업 보안 환경의 독립 검증은 미완료입니다. 회사 보안 정책을 우회하지 마세요.

창작 품질, 대사·번역·자막 정확성, 색 보정, 저작권, 법적 승인, 전체 방송·플랫폼 규격은 판정하지 않습니다. 합성 데모 결과를 실제 고객 납품 검증으로 오인하지 마세요.

실제 업무 적용 문의

기밀이 아닌 이미 승인된 납품 파일로 무료 체험한 뒤 파일 개수, 발견한 누락/변경, 실제 전체 업무시간을 기록해 보세요. 고객 영상이나 기밀 파일을 이메일로 보내지 마세요.
