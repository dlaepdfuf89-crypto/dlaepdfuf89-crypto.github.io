How to run one real evaluation

Use the private three-job timing worksheet to document complete workflow savings and export your own CSV →

  1. Identify approved files. Your team, not this program, selects the already-approved video exports.
  2. Capture the baseline. The app records local paths, file digests and declared technical attributes in a separate JSON manifest.
  3. Check your final folder. Scan a different folder that contains exactly what you plan to send to the client.
  4. Review PASS / FAIL. Inspect HTML/JSON findings. ZIP packaging requires PASS.
  5. Measure the whole job. Compare your prior QA/packaging minutes with baseline preparation, investigation, correction and packaging using the app.

This tool is a technical file integrity and selected metadata check, not an editorial, caption-language, broadcast compliance, color-quality or client-approval validator. Time savings have not been verified in real customer deliveries.
