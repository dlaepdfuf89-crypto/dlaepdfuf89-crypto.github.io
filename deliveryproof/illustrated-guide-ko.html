영상 납품 검수, 화면으로 확인하세요.

별도로 승인한 기준본 폴더와 최종 납품 폴더를 비교합니다. 앱 화면은 실제 Windows 프로그램에서 캡처했고, PASS/FAIL 보고서는 합성 시험 영상으로 직접 생성했습니다.

버전 안내: 아래 앱 화면은 내부 검증된 1.0.3 배포 후보입니다. 현재 Gumroad 유료 다운로드의 버전은 별도로 확인해야 하며, 공개 판매판이 1.0.3으로 교체됐다는 뜻이 아닙니다. 무료 평가판 R3와도 실행 파일 및 화면이 다를 수 있습니다.

실제 프로그램에서 진행하는 순서

01

1. 승인된 영상으로 기준본 만들기

  1. 담당자가 실제로 승인한 영상 파일이 모인 폴더를 선택합니다.
  2. 그 폴더 밖에 기준 JSON을 저장할 위치를 정합니다.
  3. 승인 기준본 저장을 눌러 파일 경로·SHA-256·기술 규격을 기록합니다.
02

2. 최종 납품 폴더와 비교하기

  1. 승인 기준 JSON 파일을 선택합니다.
  2. 실제로 고객에게 전달할 최종 납품 폴더를 선택합니다.
  3. 결과를 보관할 폴더를 지정하고 최종 검수를 실행합니다.

3. 결과를 읽는 방법

두 화면 모두 테스트용 합성 영상 4개로 엔진이 실제 출력한 보고서입니다. 고객 사례나 시간을 절약했다는 증빙이 아닙니다.

PASS / CREATED

PASS · 납품 ZIP 생성

검사한 4개 파일 모두 기준본과 일치하여 납품 ZIP 상태가 CREATED로 기록됐습니다.

FAIL / BLOCKED

FAIL · 납품 ZIP 차단

파일의 해시/해상도 차이를 검출했고 납품 ZIP 상태가 BLOCKED로 기록됐습니다.

사진 아래 실제 검수 보고서 전체 보기

실제 고객 영상이 아닌 합성 테스트 자료입니다. 보고서 원본과 기계 판독용 JSON을 직접 열어 구조와 오류 메시지를 확인할 수 있습니다.
