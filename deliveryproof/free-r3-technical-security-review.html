Bundled dependencies and execution

The extracted archive includes DeliveryProofEvaluation/DeliveryProofEvaluation.exe, a bundled Python 3.14 runtime (including python314.dll), Tcl/Tk GUI binaries, Python standard-library modules/extensions, runtime C libraries, cryptographic/SSL binaries, and the MediaInfo CLI. The exact bundled DLL, PYD and executable file list with hashes is below.

We executed the bundled _internal/tools/MediaInfo.exe --Version in an isolated local test and observed MediaInfoLib v26.10. The bundled _internal/tools/LIBCURL.DLL is included in the inventory. Video metadata is inspected by invoking the local MediaInfo executable using subprocess.run([...], shell=False) with --Output=JSON and an explicit selected video filename. This tool is invoked as a process on local files; we have not certified the third-party native binary's network behavior.

Included vendor licence file: DeliveryProofEvaluation/_internal/licenses/LICENSE. A portable bundle does not mean a digitally signed or independently security-certified application.

File-path validation and input handling

Folder scanning is performed locally. The operator first selects media already approved by a person and captures a separate JSON reference manifest. The software does not authenticate that approval itself. The manifest uses exact relative paths and SHA-256 hashes, plus measured width, height, duration, average FPS and the presence or absence of audio streams.

  • Rejects absolute/traversing relative paths (..), empty/ambiguous path components, unsafe Windows names and special characters.
  • Rejects symbolic links, Windows junctions, non-regular files and case-insensitive collisions in scanned inputs. Paths are checked to remain within the selected root.
  • Supports a maximum 1,000 manifest files, 20,000 scanned tree entries, 20 GiB per file, 32 relative-path components and 512-character manifest path strings.
  • Detects files that mutate while being hashed or during metadata inspection or ZIP packaging.
  • Approved baseline manifest is created outside the media folder. It is not silently overwritten, and results are saved into a new, distinct output folder.

Metadata failures and output policy

Each metadata subprocess has a 15-second per-file probe timeout; the overall run has a 300-second time budget. Malformed JSON, invalid stream layout, unsupported or incomplete video metadata, unreadable input, timeouts and changed files do not become an affirmative technical PASS. The R3 metadata parser requires exactly one video stream and validates positive finite measured video dimensions, duration and FPS.

A discrepancy in a required path, approved bytes, dimensions, duration, average FPS or declared audio requirement can result in FAIL. A missing approved hash/audio requirement can result in NEEDS_REVIEW. Only technical PASS creates a delivery ZIP; FAIL and NEEDS_REVIEW block that ZIP. Duration tolerance is 0.10 s and average FPS tolerance is 0.01 fps.

This does not check whether subtitles, language, visual quality, creative decisions, legal rights or contractual client approval are correct.

Network use and telemetry: what is and is not established

Code-level review of the six R3 application Python files found no network-client imports/calls or explicit telemetry/upload implementation in the reviewed source. The intended workflow is local file scanning and creation of local manifests, reports and delivery ZIPs. The GUI can store a small local settings file, and trial evidence may be recorded locally in a user-selected directory.

Important limit: standard Python socket and SSL extensions, cryptographic libraries and MediaInfo's LIBCURL.DLL are bundled. Source-pattern review, local-file workflow and absence of a configured cloud feature do not prove that the executable or all third-party native dependencies cannot initiate network connections. No independent process-wide network trace, penetration test, endpoint certification, or verified zero-telemetry attestation has been completed. For managed endpoints, use normal IT review and your organization's network/permission controls.
