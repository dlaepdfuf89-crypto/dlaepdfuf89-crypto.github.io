How to interpret your comparison

MATCHED (limited)

Both folders contain the same paths, every item was no larger than 100 MiB, and SHA-256 hashes of all corresponding bytes matched. This does not mean a human approved the files.

FAIL / NEEDS REVIEW

Missing, unexpected, changed or same-path size-different files fail. Files above the 100 MiB threshold or which cannot be read remain unverified; matching file sizes alone are not proof.

Privacy, compatibility and file-size constraints
  • All comparisons run in this browser tab using Web Crypto SHA-256. This page has no upload handler, external script, tracking pixel or analytics service. The file selection remains local; leaving this page discards it.
  • Choose folders in a current version of desktop Chrome or Edge; directory selection may be unavailable on other browsers, especially mobile.
  • Files up to 100 MiB are read into memory one at a time for hashing. Very large video files are not hashed by this free webpage — use the local Windows application if that is needed.
  • Paths are compared relative to the selected folder root. Case-insensitive path name collisions are treated as errors.
  • CSV reports include local relative filenames and comparison outcomes only. Review filenames before sharing reports externally.
