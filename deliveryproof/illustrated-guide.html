Step-by-step workflow

01

1. Capture an approved baseline

  1. Select a folder of video exports that your operator/client has separately approved.
  2. Choose a new JSON manifest location outside the approved folder.
  3. Run Capture Approved Baseline to record paths, SHA-256 and declared media specifications.
02

2. Verify the actual handoff folder

  1. Select the previously captured approved baseline JSON.
  2. Choose the final folder exactly as you intend to deliver it.
  3. Choose an output folder, then run Verify Final Delivery.
