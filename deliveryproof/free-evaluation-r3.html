Common questions before testing

Which folder should become the approved baseline?

Select a set of video exports separately approved by your client or responsible operator. DeliveryProof cannot decide whether those exports were accepted. Store the reference JSON outside the approved video folder.

Can I verify the same folder I used for the baseline?

The reference is a set of separately approved media. The final handoff must be a distinct folder containing what you actually intend to deliver. Capture the approved baseline first, then run verification against the final folder.

How do I run the next delivery with the same approved files?

If the previously approved baseline is still valid, Quick Verify Recent Baseline can be used for a different final folder. If the client or technical acceptance criteria have changed, obtain an updated approval rather than assuming the old baseline applies.

Do failed checks use one of my five free packages?

No. R3's quota counts up to five successfully created delivery ZIPs. A FAIL or NEEDS_REVIEW outcome blocks packaging and does not use up a successful package. Review the mismatch, correct the final exports and verify again.

Does the evaluation automatically prove how much time I saved?

No. App-observed seconds are not a complete workflow measurement. Complete Trial Evidence asks you to enter both full processes, including preparation, review, rework and packaging. Self-reported payment status is not independent proof of a purchase.

What if an unsigned Windows executable is blocked by IT?

The R3 executable is unsigned and was developer-tested on Windows 10 x64. Windows 11 and managed corporate endpoints have not been independently validated. Do not bypass SmartScreen or organizational security controls; request IT review first.
