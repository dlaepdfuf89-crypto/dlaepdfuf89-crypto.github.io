What these tools actually check

  • Browser filename/CSV matrix: approved path list vs a selected local folder's filenames only. It does not inspect the contents of a video.
  • Browser SHA-256 comparison: checks paths, sizes and file bytes of selected folders locally; files over 100 MiB are marked unverified, not incorrectly passed. Does not determine whether a cut is good.
  • Windows R4 evaluation: compares previously approved video exports against final delivery files, checks selected video metadata, and makes ZIPs only on technical PASS. Five successful ZIP packages per Windows user profile, not per IP or Gumroad account.

All demos use synthetic example content. The Windows EXE is unsigned; publisher Windows 10 validation passed, but independent Windows 11, corporate endpoint and third-party security validation are not complete. Follow your organization's security policies; do not override them.

None of these products approves caption accuracy, translation, creative direction, color grading, rights, contractual sign-off or full broadcaster/platform specifications.
