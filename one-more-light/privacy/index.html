현재 무료 앱 버전 기준 · 게시일 2026년 10월 24일

이 문서는 현재 개발된 무료 앱의 동작을 설명합니다. 정식 출시 시 계정·광고·결제·분석 기능을 도입하는 경우, 해당 기능을 활성화하기 전에 안내를 개정합니다.

1. 기록의 보관 위치

사용자가 적는 할 일 제목, 선택한 가게, 완료 여부와 완료 시각, 표시 테마 등은 해당 기기의 앱 또는 브라우저 저장공간에 보관됩니다. 현재 앱에는 회원가입, 운영자 서버로의 할 일 전송, 계정 기반 자동 동기화 기능이 없습니다.

2. 앱 권한과 외부 서비스

현재 Android 앱은 인터넷 권한을 사용하지만 위치, 연락처, 카메라, 마이크 권한을 요청하지 않습니다. 현재 앱 기능에는 광고 네트워크 SDK, 분석 SDK, 활성화된 실제 인앱결제가 포함돼 있지 않습니다. ‘프리미엄 테마’ 표시는 출시 준비 중인 미리보기이며 현재 앱에서는 결제되지 않습니다. 스토어 및 운영체제 제공자는 별도 정책에 따라 정보를 처리할 수 있습니다.

3. 기록 백업 및 공유

사용자가 JSON 백업을 직접 내보내면 할 일과 완료 이력 등이 파일에 포함될 수 있습니다. 파일을 외부 앱 또는 클라우드 서비스로 공유하는 것은 사용자의 선택이며, 선택한 서비스의 개인정보 처리방침이 적용됩니다. 백업 파일의 보관·삭제는 사용자가 관리합니다.

4. 삭제와 복원

사용자는 앱에서 개별 기록을 삭제할 수 있습니다. 앱을 제거하거나 해당 브라우저 저장공간을 지우면 로컬 기록이 사라질 수 있습니다. 다른 기기로 옮기기 전에는 JSON 내보내기로 별도 백업해야 합니다. 백업 가져오기는 기존 기록을 덮어쓸 수 있습니다.

5. 보유 기간 및 외부 제공

현재 앱에서 입력한 기록은 사용자가 수정·삭제하거나 기기의 앱 데이터를 삭제하기 전까지 로컬 저장공간에 유지됩니다. 현재 운영자가 관리하는 별도 사용자 기록 데이터베이스가 없어 서버의 보유 기간이나 외부 제공 절차는 해당하지 않습니다.

6. 문의

앱의 개인정보 처리 및 기록 관리 문의는 개발자 GitHub 문의 게시판을 이용할 수 있습니다. 공개 게시판에는 실제 할 일 기록, 개인 연락처 등 민감한 정보를 올리지 마십시오.

정식 스토어 판매 주체와 고객지원 담당자는 스토어 등록 전 최종 확정합니다.
